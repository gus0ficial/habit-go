# go-habit

## La App de CLI

**go-habit-cli** es una App de Command Line Interface (CLI), diseñada para que sus usuarios puedan gestionar sus habitos.

**Nota de desarrollo:** go-habit no es un proyecto que haya surgido para satisfacer una necesidad, sino para explorar ideas; Sin embargo, como desarrolllador, he de decir que yo mismo uso el App.
